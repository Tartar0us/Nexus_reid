## 📊 四宫格架构图

### **Problem 1: 空间特征提取与时序建模**

```
┌─────────────────────────────────────────────────────────────────┐
│                         Problem 1                               │
│              空间特征提取 + 时序注意力机制                         │
└─────────────────────────────────────────────────────────────────┘

    ┌──────────────────┐
    │  ResNet50        │ ────────┐
    │  Backbone        │         │
    │  (预训练模型)     │         │      ┌─────────────────────────┐
    └──────────────────┘         │      │  提取2048维空间特征      │
                                 ├─────▶│  每帧独立处理            │
    ┌──────────────────┐         │      │  输出: [B, 8, 2048]     │
    │  Layer4解冻      │ ────────┘      └────────────┬────────────┘
    │  (微调适配)      │                              │
    └──────────────────┘                              │
                                                      │
    ┌─────────────────────────────────────────────────▼──────┐
    │              时序注意力权重计算                          │
    │  ┌──────────────────────────────────────────────────┐  │
    │  │  频率 (Frequency)    │  Linear(2048→256)        │  │
    │  │  重要性 (Importance) │  + ReLU                  │  │
    │  │  帧间关系            │  + Linear(256→1)         │  │
    │  └──────────────────────────────────────────────────┘  │
    └─────────────────────────────────────────────────────────┘
                                  │
                                  ▼
                    ┌─────────────────────────┐
                    │  Softmax归一化           │
                    │  计算每帧注意力权重       │
                    └─────────────┬───────────┘
                                  │
                                  ▼
                    ┌─────────────────────────┐
                    │  加权聚合8帧特征         │
                    │  输出: [B, 2048]        │
                    │  (视频级表示)            │
                    └─────────────────────────┘
```

## 🎯 核心对应关系总结

### 模型组件对应
- **ARIMA/LSTM** → **ResNet50 + 时序注意力**
- **Word attributes** → **特征维度与权重**
- **Future prediction** → **特征提取与嵌入**
- **Stacking models** → **损失函数组合**

### 训练策略对应
- **Distribution analysis** → **数据增强策略**
- **Hard Mode percentage** → **困难样本比例**
- **Time evolution** → **渐进式改进路线**

### 评估指标对应
- **Tries (1,2,6,X)** → **损失函数权重**
- **Results distribution** → **CMC曲线分布**
- **EERIE classification** → **性能等级分类**

### 优化方法对应
- **PCA + GMM** → **特征分析与聚类**
- **Difficulty levels** → **样本难度分级**
- **Learning rate schedule** → **Warmup + Cosine**
