## 🏗️ 核心模型架构（分层详解）

```
┌─────────────────────────────────────────────────────────────────────┐
│                        输入: 视频序列                                 │
│                   [Batch, 8帧, 3通道, 256×128]                       │
└─────────────────────────────────────────────────────────────────────┘
                                    │
                    ┌───────────────▼───────────────┐
                    │  第1层: 空间特征提取            │
                    │  (Spatial Feature Extraction) │
                    └───────────────────────────────┘
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        │                           │                           │
        │   ┌───────────────────────▼───────────────────────┐   │
        │   │      ResNet50 Backbone (预训练)               │   │
        │   │  • Layer1-3: 冻结参数 (特征提取器)            │   │
        │   │  • Layer4: 解冻微调 (任务适配)                │   │
        │   │  • 输入: [B×8, 3, 256, 128]                  │   │
        │   │  • 输出: [B×8, 2048, 8, 4] (特征图)          │   │
        │   └───────────────────────┬───────────────────────┘   │
        │                           │                           │
        │   ┌───────────────────────▼───────────────────────┐   │
        │   │      全局平均池化 (GAP)                        │   │
        │   │  • 输入: [B×8, 2048, 8, 4]                   │   │
        │   │  • 输出: [B×8, 2048, 1, 1]                   │   │
        │   │  • Reshape: [B, 8, 2048]                     │   │
        │   └───────────────────────┬───────────────────────┘   │
        │                           │                           │
        └───────────────────────────┼───────────────────────────┘
                                    │
                    ┌───────────────▼───────────────┐
                    │  第2层: 时序注意力机制          │
                    │  (Temporal Attention)         │
                    └───────────────────────────────┘
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        │                           │                           │
        │   ┌───────────────────────▼───────────────────────┐   │
        │   │      注意力权重计算                            │   │
        │   │  • Linear(2048 → 256) + ReLU                 │   │
        │   │  • Linear(256 → 1)                           │   │
        │   │  • Softmax(dim=1) → 注意力权重 [B, 8, 1]     │   │
        │   └───────────────────────┬───────────────────────┘   │
        │                           │                           │
        │   ┌───────────────────────▼───────────────────────┐   │
        │   │      加权聚合                                  │   │
        │   │  • 特征 [B, 8, 2048] × 权重 [B, 8, 1]        │   │
        │   │  • Sum(dim=1) → 视频级特征 [B, 2048]         │   │
        │   └───────────────────────┬───────────────────────┘   │
        │                           │                           │
        └───────────────────────────┼───────────────────────────┘

                    ┌───────────────▼───────────────┐

        │                           │                           │
        │   ┌───────────────────────▼───────────────────────┐   │
        │   │      特征降维                                  │   │
        │   │  • Linear(2048 → 512)                        │   │
        │   │  • BatchNorm1d(512)                          │   │
        │   │  • 输出: 嵌入特征 [B, 512]                    │   │
        │   └───────────────────────┬───────────────────────┘   │
        │                           │                           │
        └───────────────────────────┼───────────────────────────┘
                                    │
                    ┌───────────────▼───────────────┐
                    │  第4层: 分类与度量学习          │
                    │  (Classification & Metric)    │
                    └───────────────────────────────┘
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        │                           │                           │
        │   ┌───────────────────────▼───────────────────────┐   │
        │   │      分类器 (训练时)                           │   │
        │   │  • Linear(512 → 625类)                       │   │
        │   │  • 输出: 类别logits [B, 625]                 │   │
```

## 🔑 关键技术点

### 1️⃣ 空间特征提取
- **ResNet50预训练模型**: 利用ImageNet预训练权重
- **部分冻结策略**: Layer1-3冻结，Layer4微调
- **全局平均池化**: 将空间特征图压缩为向量

### 2️⃣ 时序建模
- **注意力机制**: 自动学习每帧的重要性权重
- **加权聚合**: 将8帧特征融合为视频级表示
- **轻量设计**: 2层MLP，参数量小

### 3️⃣ 度量学习
- **Triplet Loss**: 拉近同类样本，推远异类样本
- **L2归一化**: 测试时特征归一化，使用欧氏距离
- **双重损失**: 分类损失 + 度量损失

### 4️⃣ 训练优化
- **数据增强**: 7种增强策略，提升鲁棒性
- **学习率调度**: Warmup稳定初期，Cosine平滑收敛
- **正则化**: Label Smoothing + Weight Decay + 梯度裁剪

### 5️⃣ 评估协议
- **Query/Gallery分割**: 模拟真实检索场景
- **CMC + mAP**: 双重指标全面评估
- **标准化流程**: 可复现，可对比
