## Problem 1: 空间特征提取与时序建模

### 📦 左上角模块组（对应ARIMA/LSTM）

**模块1: ResNet50 Backbone**
```
内容：
• 预训练模型：ImageNet-1K预训练权重
• 输入尺寸：256×128×3 (H×W×C)
• 输出特征：2048维特征向量
• 冻结策略：Layer1-3冻结，保留通用特征
```

**模块2: Layer4微调层**
```
内容：
• 可训练参数：约7.1M
• 学习率：3e-5 (base_lr × 0.1)
• 作用：任务特定特征适配
• 输出：[B×8, 2048, 8, 4] 特征图
```

**模块3: 全局平均池化(GAP)**
```
内容：
• 操作：AdaptiveAvgPool2d(1)
• 输入：[B×8, 2048, 8, 4]
• 输出：[B×8, 2048, 1, 1]
• Reshape：[B, 8, 2048] (批次×帧数×特征维度)
```

### 🎯 右侧输出框（对应"Predict interval"）

**框1: 提取2048维空间特征**
```
详细内容：
• 每帧独立处理：8帧视频序列分别通过ResNet50
• 特征维度：2048维/帧
• 特征类型：高层语义特征（外观、姿态、颜色）
• 输出格式：[Batch_size, 8_frames, 2048_dims]
```

### 📊 中间属性框（对应"Attributes of the word"）

**属性框标题: 时序注意力权重计算**

**子属性1: 频率(Frequency) → Linear(2048→256)**
```
内容：
• 第一层全连接：将2048维压缩到256维
• 参数量：2048 × 256 = 524,288
• 激活函数：ReLU
• 作用：提取帧级重要性的中间表示
```

**子属性2: 字母数量 → ReLU激活**
```
内容：
• 非线性变换：max(0, x)
• 作用：引入非线性，增强表达能力
• 输出：256维激活特征
```

**子属性3: 元音数量 → Linear(256→1)**
```
内容：
• 第二层全连接：256维压缩到1维
• 参数量：256 × 1 = 256
• 输出：每帧的重要性分数（未归一化）
• 形状：[B, 8, 1]
```

### 📈 下方输出框（对应百分比）

**框2: Hard Mode百分比 → Softmax归一化**
```
详细内容：
• 操作：Softmax(dim=1)
• 输入：[B, 8, 1] 原始分数
• 输出：[B, 8, 1] 注意力权重（和为1）
• 含义：每帧对最终识别的贡献度
• 示例：[0.05, 0.08, 0.15, 0.20, 0.18, 0.12, 0.10, 0.12]
```

**框3: (1,2,3,4,5,6,X)百分比 → 加权聚合**
```
详细内容：
• 操作：加权求和 Σ(特征i × 权重i)
• 输入特征：[B, 8, 2048]
• 输入权重：[B, 8, 1]
• 输出：[B, 2048] 视频级特征表示
• 物理意义：融合8帧信息为单一视频表示
```

## Problem 2: 特征嵌入与损失函数

### 📦 左上角输入模块

**模块1: 视频级特征 [B, 2048]**
```
内容：
• 来源：Problem 1的加权聚合输出
• 维度：2048维高维特征
• 包含信息：整个视频序列的综合表示
• 特点：时序信息已融合
```

**模块2: 特征降维处理**
```
内容：
• Linear层：2048 → 512维
• 参数量：2048 × 512 = 1,048,576
• BatchNorm1d：归一化512维特征
• 作用：降低计算复杂度，提取关键特征
```

### 🎯 中间分布框（对应"Distribution of the reported results"）

**分布分析标题: 双重损失函数**

**1 try → Label Smoothing Cross Entropy**
```
详细内容：
• 公式：L_CE = -Σ y_smooth × log(p)
• Smoothing参数：ε = 0.1
• 平滑后标签：y_smooth = (1-ε)×y_true + ε/N_class
• N_class = 625（训练集人数）
• 作用：防止过拟合，提升泛化能力
• 权重：1.0（主损失）
```

**2 tries → Triplet Loss参数**
```
详细内容：
• 公式：L_tri = max(0, d(a,p) - d(a,n) + margin)
• Margin：0.3
• d(·,·)：欧氏距离
• 采样策略：Batch内Hard Mining
  - Anchor：当前样本
  - Positive：同PID最远样本
  - Negative：不同PID最近样本
```

**6 tries → Triplet Loss权重**
```
详细内容：
• 权重系数：0.5
• 总损失：L_total = L_CE + 0.5 × L_tri
• 平衡策略：分类损失为主，度量损失为辅
• 训练稳定性：权重0.5避免Triplet Loss主导
```

**X tries → 优化器配置**
```
详细内容：
• 优化器：AdamW
• 学习率分层：
  - Layer4: 3e-5 (微调)
  - Attention: 3e-4 (正常)
  - Embedding: 3e-4 (正常)
  - Classifier: 3e-4 (正常)
• Weight Decay：5e-4
• Betas：(0.9, 0.999)
```

### 📊 下方Stacking模块

**Linear models → AdamW优化器**
```
详细内容：
• 参数组1：Layer4 (lr=3e-5)
• 参数组2：Attention (lr=3e-4)
• 参数组3：Embedding (lr=3e-4)
• 参数组4：BatchNorm (lr=3e-4)
• 参数组5：Classifier (lr=3e-4)
• 总参数量：约25.8M
```

**Tree models → 梯度裁剪**
```
详细内容：
• 方法：torch.nn.utils.clip_grad_norm_
• Max Norm：5.0
• 作用：防止梯度爆炸
• 应用时机：loss.backward()之后，optimizer.step()之前
• 裁剪策略：如果梯度范数>5.0，则缩放到5.0
```

### 🎯 最终输出框

**Predict "EERIE" → 预测嵌入特征**
```
详细内容：
• 训练时输出：
  - Logits: [B, 625] 类别预测
  - Embedding: [B, 512] 特征向量
• 测试时输出：
  - Normalized Embedding: [B, 512] L2归一化特征
  - 用于：计算Query-Gallery距离矩阵
• 距离度量：欧氏距离 d = ||feat_q - feat_g||₂
```

## Problem 4: 学习率调度与性能分析

### 📦 左上角输入模块

**模块1: 训练历史与新属性**
```
详细内容：
• 训练轮数：60 epochs
• 批次大小：16
• 序列长度：8帧/tracklet
• 训练样本：8,298个tracklet
• 训练时间：约4-5小时 (RTX 4060 Laptop)
• 检查点保存：每10轮 + best + final
```

**模块2: 学习率调度策略**
```
详细内容：
• Warmup阶段（Epoch 1-5）：
  - 初始LR：0
  - 目标LR：3e-4
  - 增长方式：线性增长
  - 公式：lr = base_lr × (epoch+1) / warmup_epochs

• Cosine退火阶段（Epoch 6-60）：
  - 起始LR：3e-4
  - 最小LR：1e-6
  - 公式：lr = min_lr + (base_lr - min_lr) × 0.5 × (1 + cos(π×progress))
  - progress = (epoch - warmup) / (total - warmup)

• 学习率曲线特点：
  - Epoch 1-5: 0 → 3e-4 (线性上升)
  - Epoch 6-30: 3e-4 → 1.5e-4 (快速下降)
  - Epoch 31-60: 1.5e-4 → 1e-6 (平滑下降)
```
