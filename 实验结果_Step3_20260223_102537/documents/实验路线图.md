# 视频行人重识别实验改进路线图

## 当前Baseline性能
- **Rank-1**: 19.73%
- **Rank-5**: 31.49%
- **mAP**: 12.90%

## 改进路线

### 第一步：解冻Backbone + Triplet Loss（必做）✅
**文件**: `train_improved_step1.py`, `eval_improved_step1.py`

**改进内容**:
1. 解冻ResNet50的layer4层
2. 加入Triplet Loss（margin=0.3）
3. 使用不同学习率（layer4用0.1x，其他层用1x）
4. 训练60轮

**预期提升**: Rank-1 +10-20%, mAP +5-15%

**运行命令**:
```bash
# 训练
python train_improved_step1.py

# 评估
python eval_improved_step1.py

# 评估特定epoch的模型
python eval_improved_step1.py model_step1_epoch30.pth
```

**关键参数**:
- Batch size: 16
- Base LR: 3e-4
- Layer4 LR: 3e-5
- Triplet weight: 0.5
- Scheduler: StepLR (step=20, gamma=0.5)

---

### 第二步：ConvLSTM时序建模 ✅
**文件**: `train_improved_step2.py`

**改进内容**:
1. 替换简单attention为ConvLSTM
2. 2层ConvLSTM，hidden_dim=512
3. 保留Triplet Loss
4. 训练60轮

**预期提升**: 在Step1基础上 Rank-1 +5-10%, mAP +3-8%

**运行命令**:
```bash
# 训练
python train_improved_step2.py

# 评估（使用相同的评估脚本，修改模型路径）
python eval_improved_step1.py final_model_step2.pth
```

**关键参数**:
- Batch size: 8（ConvLSTM显存占用大）
- ConvLSTM layers: 2
- Hidden dim: 512
- Kernel size: 3

**注意事项**:
- ConvLSTM显存占用较大，如果OOM，减小batch size到4
- 训练时间会比Step1长约1.5-2倍

---

### 第三步：数据增强 + 训练策略优化 ✅
**文件**: `train_improved_step3.py`

**改进内容**:
1. 增强的数据增强:
   - RandomHorizontalFlip
   - RandomCrop with padding
   - ColorJitter
   - RandomGrayscale
   - RandomErasing
2. Label Smoothing (0.1)
3. Warmup学习率 (5 epochs)
4. Cosine Annealing调度
5. AdamW优化器
6. 梯度裁剪

**预期提升**: 在Step1基础上 Rank-1 +3-8%, mAP +2-5%

**运行命令**:
```bash
# 训练
python train_improved_step3.py

# 评估
python eval_improved_step1.py final_model_step3.pth
```

**关键参数**:
- Label smoothing: 0.1
- Warmup epochs: 5
- Optimizer: AdamW
- Gradient clip: 5.0

## 实验执行顺序

### 推荐顺序（按优先级）:
1. **Step1** - 最直接有效，必须先做
2. **Step3** - 在Step1基础上，提升泛化能力
3. **Step2** - 如果前两步效果好，再尝试更复杂的时序建模

### 时间估算:
- Step1训练: ~2-3小时（60 epochs）
- Step2训练: ~4-5小时（ConvLSTM慢）
- Step3训练: ~2-3小时
- 每次评估: ~5-10分钟

---

## 调试建议

### 如果Step1效果不好:
1. 检查学习率是否合适
2. 尝试调整Triplet Loss权重（0.3-0.7）
3. 增加训练轮次到100轮
4. 检查是否有梯度爆炸/消失

### 如果Step2显存不足:
1. 减小batch size到4或2
2. 减少ConvLSTM层数到1层
3. 减小hidden_dim到256

### 如果Step3过拟合:
1. 增加Label Smoothing到0.15
2. 增加weight decay
3. 增加RandomErasing概率
